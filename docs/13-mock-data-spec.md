## 4. Data integrity rules for the generator
- DOB → DOJ ≥ age 20. DOR = end of month of the 61st birthday (assumption).
- Loans start only after DOJ and never extend beyond DOR (respects BR-002).
- Schedules, demand components, receipts and allocations must reconcile: Σ allocations = receipt amount. Σ allocated per component ≤ demand.
- Share deposit balances = Σ BR-004 deductions from disbursed Ordinary loans + seeded opening balance.
- Transfers: 12 members with transfers, including 2 that took effect in the current cycle (BR-010 demo).
- Every in-process loan has a consistent LoanEvent history.
